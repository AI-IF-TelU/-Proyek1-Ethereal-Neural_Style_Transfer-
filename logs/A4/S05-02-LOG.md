## 2. TAHAP PENANGANAN EROR / DEBUGGING
### Pesan Eror
```text
(eval):1: ====F4C2 not found
```
```text
cat: illegal option -- A
usage: cat [-belnstuv] [file ...]
```

### Prompt Perbaikan ke LLM
```text
Tidak ada prompt perbaikan dari A4; kedua error ditangani AI dalam sesi yang sama.
```

### Analisis & Solusi Kelompok
- `====F4C2 not found`: zsh kembali menafsirkan `====` di awal argumen `echo`
  sebagai ekspansi (kasus yang sama dengan S05-01). Perintah diulang tanpa
  pemisah tersebut.
- `cat -A` tidak ada di `cat` macOS (BSD). Pemeriksaan isi file dilakukan
  langsung dengan `cat` biasa.
- Bukan error program, tetapi temuan proses: versi pertama skrip audit
  menganggap hampir semua log tidak lengkap karena mencocokkan `- Nama
  Kelompok:` secara persis, sedangkan banyak log menulis `- **Nama
  Kelompok:**`. Skrip diperbaiki agar membuang `**` dan mencocokkan judul
  `## 0.`–`## 3.` berdasarkan nomor, lalu hasilnya dicek manual.

### Pelajaran
- Audit format otomatis harus toleran terhadap variasi Markdown; hasil awal
  yang "semuanya gagal" adalah tanda aturan pencocokannya terlalu kaku.
- Status di dalam file log perlu diperbarui setelah handoff disetujui, atau
  cukup merujuk ke `docs/HANDOFF.md`, agar tidak ada dua sumber status yang
  bertentangan.
