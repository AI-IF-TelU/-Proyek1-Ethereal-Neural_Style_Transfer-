## Implementasi dan review
- Fungsi `load_image(image_path, size=None)` menerima str/Path.
- Format diperiksa dari isi oleh Pillow, bukan ekstensi saja.
- RGBA membuang alpha; grayscale menjadi tiga kanal RGB.
- File tidak ditemukan menghasilkan FileNotFoundError dengan path.
- File tidak dikenali/format tidak didukung menghasilkan ValueError.
- Kegagalan akses/decode mempertahankan OSError dari Pillow.
- Review mandiri: context manager menutup file; hasil konversi dapat dipakai
  setelah file sumber dihapus; tidak ada perubahan ke model atau loss.
- Placeholder dengan escaped triple quote pada kedua file diganti kode valid.
