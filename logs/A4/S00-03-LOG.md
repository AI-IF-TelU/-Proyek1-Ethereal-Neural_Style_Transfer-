## 2. TAHAP PENANGANAN EROR / DEBUGGING
### Pesan Eror
```text

```
```text
(eval):1: no matches found: --include=*.py
```

### Prompt Perbaikan ke LLM
```text
Tidak ada prompt perbaikan dari A4; kedua error ditangani AI dalam sesi yang sama.
```

### Analisis & Solusi Kelompok
- Error pertama adalah diagnostik VS Code (Pylance) pada
  `tests/test_log_interaction.py`. Editor masih menunjuk ke interpreter
  `.venv` lama (Python 3.14), padahal `.venv` sudah dibuat ulang dengan
  Python 3.12 di awal sesi. Pytest dari terminal tetap berjalan normal.
  Solusi: pilih ulang interpreter di VS Code (Cmd+Shift+P → "Python: Select
  Interpreter" → `.venv`). Ini bukan bug kode.
- Error kedua terjadi saat mencari referensi skrip dengan `grep`, karena zsh
  memperluas `--include=*.py` sebagai glob. Solusi: pola diberi tanda kutip
  (`--include='*.py'`).

### Pelajaran
- Uji skrip yang menulis file harus diarahkan ke file sementara agar log asli
  tidak tercemar.
- Skrip pencatat sebaiknya gagal jika argumen wajib kosong, bukan diam-diam
  menulis entri kosong.
- Setelah membuat ulang virtual environment, interpreter di editor juga harus
  dipilih ulang.
