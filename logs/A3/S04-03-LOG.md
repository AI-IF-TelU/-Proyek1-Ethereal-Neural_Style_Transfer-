## 2. TAHAP PENANGANAN EROR / DEBUGGING

### Pesan Eror
```text
FAILED tests/test_losses.py::TestStyleLoss::test_autograd_flow_to_all_layers - AssertionError: assert (tensor.grad != 0).any() where tensor.grad == 0
```

### Prompt Perbaikan ke LLM
Investigasi mengapa `tensor.grad` bernilai nol pada seluruh elemen saat pengujian autograd `test_autograd_flow_to_all_layers`.

### Analisis & Solusi Kelompok
- **Penyebab:** Pada unit test awal, fitur input `gen_dict` diinisialisasi persis sama dengan target gaya `dummy_feature_maps`. Karena loss yang dihitung adalah Mean Squared Error $(x - x_0)^2$, turunan pertama terhadap $x$ pada titik minimum eksak $x = x_0$ bernilai identik nol ($2(x - x_0) = 0$). Hal ini menyebabkan gradien yang dihasilkan autograd bernilai nol meskipun grafik komputasi terhubung sempurna.
- **Solusi:** Memberikan *offset* nilai pada fitur uji `gen_dict` (misalnya `feat + 0.5`) sehingga evaluasi tidak berada di titik stasioner minimum global, membuktikan bahwa gradien non-nol mengalir lancar ke seluruh layer input.

### Pelajaran
Dalam pengujian aliran gradien *autograd*, tensor input tidak boleh dievaluasi tepat pada titik minimum absolut loss (di mana loss = 0), melainkan harus memiliki deviasi dari target agar gradien bernilai nyata dan dapat diuji keterhubungannya.
