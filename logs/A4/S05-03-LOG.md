### Analisis & Solusi Kelompok
- **RuntimeError L-BFGS (Temuan #11, bug integrasi nyata).** Diperiksa langsung:
  ```text
  preprocess_image(...) -> shape (1, 3, 32, 48), stride (3, 1, 144, 3), contiguous False
  .detach().clone()     -> contiguous False
  torch.randn(1,3,32,48) -> contiguous True
  ```
  `preprocess_image` (A2) memakai `permute(2, 0, 1)`, sehingga tensornya
  berstride *channels-last*. `run_style_transfer` (A3) menyalinnya dengan
  `clone()` yang mempertahankan stride, dan gradiennya ikut berstride sama.
  `torch.optim.LBFGS` memanggil `p.grad.view(-1)`, yang gagal untuk memori
  tidak kontigu. Adam tidak terdampak. Unit test A3 tidak menangkapnya karena
  memakai `torch.randn` yang kontigu; artinya pipeline asli (gambar →
  L-BFGS, optimizer default) akan gagal di Stage 6.
  - Solusi: di `src/optimization.py`, salinan awal memakai
    `clone(memory_format=torch.contiguous_format)`. Dipilih di sini, bukan di
    `src/preprocessing.py`, karena (1) berkas A2 tidak boleh diubah A4,
    (2) satu titik ini melindungi input dari sumber mana pun, dan (3)
    kontrak D-005/D-008 tidak berubah. Test tidak diakali dengan
    `.contiguous()`, agar bug tetap terdeteksi bila perbaikan dicabut.
  - **Catatan izin:** izin A1 di Handoff #8 hanya mencakup guard
    `isinstance`. Perubahan satu titik ini di luar izin tersebut dan perlu
    dikonfirmasi A1 (mudah dicabut; test regresi
    `test_lbfgs_accepts_non_contiguous_input` akan gagal bila dicabut).
    Alternatif bagi A2: menambahkan `.contiguous()` di akhir
    `preprocess_image`.
- **E302/E305 di `main.py`:** sebelumnya tertutup E901 karena file tidak bisa
  di-parse. Diperbaiki dengan baris kosong.

### Pelajaran
- Unit test dengan tensor sintetis (`torch.randn`) tidak menjamin modul cocok
  dengan keluaran modul lain; stride/memory format juga bagian dari kontrak
  antarmodul. Integration test dengan keluaran asli modul sebelumnya wajib.
- Memperbaiki SyntaxError bisa memunculkan pelanggaran lint lain yang
  sebelumnya tersembunyi; jalankan ulang linter setelah perbaikan.
