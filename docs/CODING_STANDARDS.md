# CODING_STANDARDS

- PEP 8
- snake_case untuk fungsi/variabel
- PascalCase untuk class (jika ada)
- Type hints wajib untuk fungsi publik
- Docstring (ringkas, jelas)
- Hindari hardcode berlebihan - pakai config
- Imports terkelompok
- Modular
- Reproducibility (torch.manual_seed)
- Jangan log kredensial
