## 1. TAHAP EKSEKUSI PENGUJIAN (`tests/test_feature_extractor.py`)

### A. Lingkungan Pengujian Lokal (`.venv`)

- **Paket Utama:** `torch==2.14.1+cpu`, `torchvision==0.29.1+cpu`, `pytest==9.1.1`, `pillow==12.2.0`, `numpy==2.4.6`

### B. Ringkasan 9 Metode Uji & 17 Subtests pada `tests/test_feature_extractor.py`
1. `test_default_signature_and_layer_constants` — Memverifikasi default `weights=VGG19_Weights.DEFAULT`, `device="cpu"`, serta konstanta `DEFAULT_LAYERS`, `CONTENT_LAYERS`, `STYLE_LAYERS`, dan `MAX_FEATURE_LAYER_INDEX == 28`. (**PASSED**)
2. `test_model_truncation_eval_mode_frozen_weights_and_non_inplace_relu` — Memverifikasi `len(model) == 29`, `model.training is False`, seluruh parameter `requires_grad is False`, dan seluruh `nn.ReLU` memiliki `inplace is False`. (**PASSED**)
3. `test_feature_shapes_square_non_square_and_batched` — Memverifikasi dimensi ke-6 peta fitur (`conv1_1`..`conv5_1`, `conv4_2`) pada input persegi `(1, 3, 64, 64)`, non-persegi `(1, 3, 64, 128)`, dan *batched* `(2, 3, 32, 48)` (3 subtests). (**PASSED**)
4. `test_conv_outputs_not_mutated_inplace_by_subsequent_relu` — Membuktikan keluaran `features["conv1_1"]` identik dengan `model[0](tensor)` dan tetap mempertahankan nilai aktivasi negatif tanpa terpotong oleh `ReLU` pada indeks `1`. (**PASSED**)
5. `test_autograd_gradient_flows_to_input_image_and_not_vgg_parameters` — Membuktikan `loss.backward()` menghasilkan `generated.grad` berdimensi `(1, 3, 32, 32)` yang *finite* dan tak-nol, sementara seluruh parameter VGG-19 tetap `param.grad is None` dan nilainya tidak berubah. (**PASSED**)
6. `test_custom_layers_and_early_exit_stops_execution` — Membuktikan lewat `unittest.mock.patch` bahwa *forward pass* berhenti pada layer terakhir yang diminta tanpa mengeksekusi layer di bawahnya. (**PASSED**)
7. `test_integration_with_stage2_preprocess_image` — Menguji integrasi langsung `preprocess_image(pil_img, size=(64, 96))` (modul Stage 2 / A2) ke `get_features(tensor, model)` (modul Stage 3 / A1). (**PASSED**)
8. `test_invalid_inputs_raise_expected_exceptions` — Menguji 14 kasus input tidak valid (`TypeError` dan `ValueError` untuk bukan tensor, dimensi 3D/5D, batch 0, channel $\neq 3$, ukuran spasial $< 16$, dtype integer, nilai `NaN`/`Inf`, dictionary layer kosong/duplikat/tidak ditemukan, dan ketidakcocokan `device`). (**PASSED**)
9. `test_cuda_device_placement_when_available` — Dilewati secara otomatis (`SKIPPED`) pada lingkungan CPU melalui `@unittest.skipUnless(torch.cuda.is_available(), "CUDA tidak tersedia")`.
