## 2. TAHAP PENANGANAN EROR / DEBUGGING

### Pesan Eror
```text
Parse error on line 31:
...L -->|Backward Pass (Autograd)| OPT["Opt
-----------------------^
Expecting ..., 'PIPE', ..., got 'PS'
```

### Prompt Perbaikan ke LLM
> "Pada bagian Arsitektur & Alur Kerja diagram Mermaid di README.md dan ARCHITECTURE.md, terjadi parse error saat dirender di GitHub:
> 'Expecting ..., got PS' pada baris Backward Pass (Autograd).
> Analisis penyebab error dan berikan perbaikan sintaks agar diagram dapat dirender sempurna di GitHub."

### Analisis & Solusi Kelompok
* **Penyebab:** Karakter kurung buka `(` pada label panah `|Backward Pass (Autograd)|` dibaca oleh parser Mermaid sebagai token `'PS'` (*Parenthesis Start*) yang merupakan reserved character untuk membuat bentuk node bulat.
* **Solusi:** Mengapit teks label dengan tanda kutip ganda: `|"Backward Pass (Autograd)"|` serta memisahkan percabangan `CL --> TL` dan `SL --> TL`.
* **Pelajaran:** Semua label panah di Mermaid yang memuat karakter khusus atau tanda kurung wajib diapit tanda kutip ganda.
