## 2. TAHAP PENANGANAN EROR / DEBUGGING

### Pesan Eror
```text
warning: in the working copy of '.gitignore', logs/* will ignore log files
```
*(Saat inspeksi Git add, ditemukan bahwa file `LOG_TEMPLATE.md`, `interactions.jsonl`, dan folder `logs/A1` s.d. `logs/A4` tidak terdeteksi oleh Git).*

### Prompt Perbaikan ke LLM
> "Di file .gitignore terdapat baris `logs/*`. Hal ini menyebabkan berkas template log dan riwayat percakapan anggota tidak terdeteksi oleh Git. Padahal log interaksi berbobot 25% dari total nilai tugas besar.
> Perbaiki aturan .gitignore agar hanya mengabaikan file biner/sistem (.log) namun tetap melacak seluruh berkas markdown di dalam folder logs/."

### Analisis & Solusi Kelompok
* **Penyebab:** Pola `logs/*` mengabaikan seluruh isi subfolder logs tanpa pandang bulu.
* **Solusi:** Mengubah aturan menjadi:
  ```gitignore
  # Logs
  *.log
  !logs/
  !logs/**
  ```
  Serta menambahkan file `.gitkeep` pada masing-masing subdirektori `logs/A1/`, `logs/A2/`, `logs/A3/`, dan `logs/A4/`.
* **Pelajaran:** Aturan `.gitignore` untuk direktori pencatatan non-biner harus dikonfigurasi secara selektif agar dokumentasi anggota tim tetap tersimpan di repositori GitHub.
